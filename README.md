# Event Organizer

## Overview
A C# Windows Forms application developed as part of the Programming in C# I course at Malmö University.

The application is designed to manage events and their participants, including personal information and address details.

## Features
- Create and manage events.
- Add new participants.
- Edit existing participant information.
- Remove participants.
- Manage participant addresses.
- Calculate total event costs and fees.
- Display participant information through a graphical user interface.

## Technologies
- C#
- .NET
- Windows Forms
- Object-Oriented Programming (OOP)

## Concepts
- Encapsulation
- Data Hiding
- Classes and Objects
- Properties and Constructors
- Collections (`List<T>`)
- Object Relationships

## Project Structure
- `Address.cs` – Address information.
- `Countries.cs` – Country enumeration.
- `Participant.cs` – Participant information.
- `ParticipantManager.cs` – Participant management.
- `EventManager.cs` – Event management.
- `Isra.cs` – Main application interface.
- `Program.cs` – Application entry point.

## Purpose
This project demonstrates object-oriented programming principles through the development of a Windows Forms event management application.
